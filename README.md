# SCT_DA_3
## IBM HR Employee Attrition Dashboard - Tableau Public
## Project Overview
This project analyzes employee attrition patterns using the IBM HR Analytics dataset. The dashboard was created in Tableau Public to identify attraction trends across departments, job roles, and gender.
## Dashboard Insights
- Attrition by Department
- Attrition by Job Role
- Attrition by Gender
## Tools used
- Tableau Public
- IBM HR Analytics Dataset
